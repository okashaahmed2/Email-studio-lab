**The order we move through**

1. **A quick Python refresher.** If you taught yourself Python, this is a calm chance to check the basics before we move on.
2. **pandas.** This is a Python tool for working with tables of data, like a spreadsheet you control with code.
3. **SQL.** This is a language for getting data out of databases.
4. **Data visualisation.** This means turning data into clear charts that tell a story.
5. **Machine learning basics.** This is where you teach a computer to find patterns in data.

Along the way, you finish 4 real projects using real public datasets. Your mentor reviews each one. By the end, you have a portfolio you can show to employers.
