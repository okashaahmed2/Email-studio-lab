# Leads folder rules

These rules apply to this folder only.

1. **These are made-up practice people.** Everyone in this folder is invented for testing. None of them is a real lead or student.
2. **Never add real people or real email addresses.** Only add made-up names, and only use addresses that end in `@example.com`.
3. **Every row needs a consent value.** Don't add or keep a row with an empty `consent` column.
4. **Never change the `@example.com` addresses.** This domain is reserved and can never receive mail, so it keeps real people from being emailed by mistake.
